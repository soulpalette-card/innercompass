# 灵墟问道 — 修仙挂机游戏

一个纯前端、无需构建工具的放置类（idle/incremental）修仙游戏。角色自动打坐修炼、自动出手打怪，哪怕关掉页面也会按离线时长估算收益；你只需要偶尔回来突破境界、装备掉落的法宝装备、挑一挑功法和出战宠物就行。

直接用浏览器打开 `index.html` 即可游玩（双击文件、`file://` 协议也能跑），也可以用任意静态文件服务器托管，例如：

```bash
python3 -m http.server 8000
```

## 核心玩法循环

**打坐修炼（被动）→ 打怪掉落（自动战斗）→ 攒够修为突破境界 → 变强 → 解锁更强的怪物/地图/秘境 → 循环**

- 每秒自动增加修为（打坐速度取决于境界、功法、宠物、法宝加成），同时自动挑一只怪物打，胜负按双方攻防数值瞬间结算（不是逐回合动画），战斗日志滚动展示最近几条战报。
- 修为攒够当前小层的阈值后，去主界面点"突破"，用一次性判定决定是否突破成功；失败不会清空进度，只会扣一部分已囤积的修为，输光了也顶多是"闭关疗养"几秒，不会真正死亡或者掉装备。
- 关掉页面/切走浏览器都没关系：重新打开时会按离线时长自动结算这段时间的修为、灵石、材料、装备、法宝、宠物收益（有上限和折扣，见下文"离线收益"）。

## 境界与修为

九个大境界，每个大境界内有若干小层，小层修为阈值按指数曲线增长：

练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫

- 前 8 个境界各 9 层，渡劫境有 13 层，是目前的终点（渡劫顶层即"目前版本的封顶"）。
- 境界内小层突破成功率较高，跨大境界的突破成功率明显更低，但修为囤积超出阈值越多、成功率会有加成（有上限）；破境丹可以进一步提升下一次突破的成功率。
- 突破失败只会扣除一部分已囤积的修为，不会清空进度或者惩罚装备/等级，可以放心反复尝试。
- 设置页可以打开"自动突破"：条件满足时每秒自动尝试一次，不用手动点；离线期间则会连续结算到失败一次为止（避免离线收益无脑刷到叠加惩罚）。
- 修炼速度（每秒获得的修为）会随小层数连续、平滑地提升，不是只有跨大境界那一下才变化，功法、宠物、法宝的"修炼速度"加成也会叠加进来。

## 战斗与属性

四维属性：**气血（HP）/ 攻击（ATK）/ 防御（DEF）/ 速度（SPD）**。基础值由当前境界+小层的连续成长曲线决定，装备、法宝、功法、宠物、炼丹永久加成都会叠加在这个基础值上。

- 怪物按"玩家当前基础属性 × 怪物自身倍率 × 难度系数"现场生成，会自动跟着玩家变强而变强，不需要为每个境界单独配平数值。
- 怪物分四档：杂兵（weak）/普通（normal）/精英（elite）/首领（boss），强度和奖励依次提升，选怪时会按"离玩家当前境界的远近"加权，越贴近当前境界的怪物越常遇到。
- 出战宠物（最多 3 只）会额外贡献一条"宠物伤害"加到每回合的输出上，同时按类型（见"宠物"一节）分别影响生存、修炼速度或自身伤害。

## 装备（掉落时现场生成，百分比加成）

五个装备槽位：**武器 / 护甲 / 饰品 / 鞋子 / 护手**。

装备不是固定的目录商品，而是**每次掉落时现场生成的独立实例**：稀有度（普通/优良/精良/极品）随机决定强度倍率，加成数值按"击杀怪物的等级"计算，全部是百分比加成（`+X% 攻击` 而不是 `+15 攻击`），所以打到后期数值涨到万/亿级别也不会变得毫无意义。每个槽位有自己主打的属性（比如武器主打攻击、护甲主打气血+防御），名字也会随稀有度和随机词条变化（比如"精良青锋剑""极品玄冥战袍"）。

装备只能靠打怪/秘境/离线掉落获得，商店不上架装备，但可以把不用的装备卖掉换灵石。

## 法宝（三个固定槽位）

法宝分三类，各占一个独立槽位，互不冲突：**攻击类 / 防御类 / 增幅类**（增幅类同时小幅加成多个属性）。法宝同样是百分比加成，稀有度越高加成越强，最高档的法宝需要挑战首领级怪物或秘境才有机会拿到。法宝可以在商店抽卡式购买，也能靠打怪掉落。

## 宠物（捕获、培养、多宠出战、融合）

- 击杀特定怪物时有几率捕获对应的宠物幼崽，捕获等级约为来源怪物等级的一半，品质（普通/优良/精良/极品）随机决定加成倍率。
- 宠物有三种类型，加成侧重点不同：
  - **陆地**：加成集中在气血、防御（更抗揍）
  - **飞行**：加成集中在修炼速度（打坐更快）
  - **海洋**：加成集中在自身出手伤害（每回合额外多打一份伤害）
- 宠物有 5 个通用段位（妖兽 → 魔兽 → 邪兽 → 圣兽 → 神兽），随等级自动提升，等级靠出战时的战斗胜利经验积累。
- 最多可以同时出战 3 只宠物，加成同时生效。
- 用不上的宠物可以"融合"献祭给另一只：被献祭宠物已投入的经验按比例转移给目标宠物，帮目标快速升级（融合前需要先把被献祭宠物下场，且是不可撤销的操作）。

## 功法（被动技能）

修习功法需要消耗灵石，达到境界要求才能修习；已修习的功法**全部同时生效、可以叠加**，不是只能选一个。目前包含修炼速度、气血/防御、攻击方向的功法，境界越高解锁的功法越强。

## 炼丹（材料合成 + 丹药融合）

- 用打怪掉落的材料按固定配方炼制丹药：聚气/破境/疗伤/攻防速血四维养成丹，都可以一键炼制（凑够材料即可，支持一键 x10 批量炼制，材料不够会自动少做几个而不是完全卡住）。
- 修为丹有一条独立的**融合升级链**：3 颗聚气丹融合成 1 颗更高阶的凝气丹，3 颗凝气丹融合成元气丹，3 颗元气丹再融合成太乙丹——每升一级单次收益大幅提升。
- 终极配方"天劫丹方"需要同时集齐炼虚、合体、大乘、渡劫四个高境界的稀有材料才能炼制，是目前修为收益最高的丹药，象征"打穿全部现有高境界内容"的里程碑。

## 商店

每天（按本地时间）自动刷新一批随机库存（法宝/丹药/材料混合），也可以花灵石手动刷新（花费随刷新次数递增，次日重置）。可以出售身上多余的法宝、材料、丹药，以及打怪掉落但没装备的装备（装备走独立的按稀有度+等级定价，不占库存位）。

## 地图（掉落侧重选择）

每个境界解锁两张地图，怪物强度完全一样，只是**掉落侧重不同**：

- **矿脉秘境**：装备、材料掉落率提升，法宝、宠物掉落率降低
- **灵兽秘境**：法宝、宠物掉落率提升，装备、材料掉落率降低

切换地图免费且立即生效，之前境界的地图也可以随时回去刷，主界面会显示当前所在地图。

## 秘境挑战（精英秘境 / 魔王秘境）

花费灵石挑战一只被强化过的首领级怪物，通关必得法宝（魔王秘境奖励更好、花费也更高）。

- **可以自由选择要挑战哪个境界的秘境**，从练气到渡劫全部开放，**不需要先达到那个境界**——想不想挑战更高境界的秘境，自己判断实力，打不过就是进入闭关疗养而已。
- 秘境的怪物强度和掉落等级都按你选择的境界计算，不是按你自己的境界，所以低境界秘境不能用来"低成本刷高级装备"。
- 如果挑战秘境时你正好在打一只普通怪物，普通战斗会被自动暂停（保留剩余血量），秘境挑战结束后（无论胜负）自动恢复继续打。

## 高境界专属内容（炼虚 ~ 渡劫）

化神境以上曾经完全没有专属怪物，只能靠低境界杂兵数值放大凑数。现在炼虚、合体、大乘、渡劫四个境界各有一套专属的普通/精英/首领怪物（共 12 只），配套专属掉落材料、装备、法宝和宠物种类，渡劫境的"九天雷劫兽"是目前的最终首领。

## 离线收益

关闭页面后再打开会自动结算这段时间的收益：

- 离线时长有上限（超过部分不计），且按固定效率打折（不是 1:1 全额收益）。
- 收益用"怪物池加权平均值"估算，而不是逐秒模拟战斗，所以哪怕离线一整天，重新打开也是瞬间结算，不会卡顿。
- 修为、灵石、材料、装备、法宝、宠物捕获、宠物经验、连续突破都会一并结算，离线时间较长时会弹出一次性的"离线收益"总结弹窗。

## 存档

- 自动存档：每 10 秒一次，以及每次手动操作（装备、使用道具、突破、挑战秘境等）后立即存档。
- 存档位置：浏览器 `localStorage`，键名 `cultivation_game_save_v1`。
- 设置页支持手动导出/导入 JSON 存档（复制粘贴文本），以及重置存档；旧版本存档会自动迁移到最新的存档结构，不会因为版本升级而损坏或重置。

## 文件结构

```
index.html          入口页面：Tailwind CDN、字体、各屏幕的 HTML 结构
css/style.css        进度条、翻牌弹窗、悬浮提示、稀有度配色等自定义样式
js/namespace.js       全局命名空间 CULT 与通用工具函数
js/icons.js           怪物光环、图鉴图标等内联 SVG 生成函数
js/data.js            所有数值表：境界、地图、怪物、法宝、宠物、装备、丹药、材料、配方、功法，以及可调参数 CULT.TUNING
js/state.js           存档结构、读写、版本迁移（含旧存档兼容逻辑）、导出/导入
js/combat.js          属性计算、怪物生成、战斗结算、装备/掉落生成、突破逻辑、宠物养成
js/offline.js         离线收益的估算与结算（用怪物池均值近似，避免逐秒模拟）
js/game.js            每秒一次的挂机主循环，以及装备、使用道具、突破、商店、炼丹、秘境挑战等所有玩家操作入口
js/ui.js              所有屏幕渲染、弹窗交互、悬浮提示内容
js/main.js            启动流程：读档 → 离线结算 → 渲染 → 开始主循环
```

## 调数值

所有可调数值都集中在 `js/data.js`，调整这些数字不需要碰任何逻辑文件：

- `CULT.REALMS`：境界名称、小层数、修为阈值曲线（`baseExpToNext` / `growth`）
- `CULT.TUNING`：修炼速度、突破成功率、失败惩罚、怪物难度系数、离线收益上限与效率、宠物/秘境/商店/装备相关的全部系数
- `CULT.MONSTERS`：怪物名称、境界、档位、属性倍率、掉落表（经验/灵石/材料/装备/法宝/宠物）
- `CULT.FABAO` / `CULT.PET_SPECIES` / `CULT.PET_STAGES` / `CULT.PET_TYPES` / `CULT.MATERIALS` / `CULT.CONSUMABLES` / `CULT.RECIPES` / `CULT.TECHNIQUES` / `CULT.MAP_TYPES`：对应系统的具体数值表
